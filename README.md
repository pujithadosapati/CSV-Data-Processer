## CSV Data Processor Using Python
## Project Overview
The CSV Data Processor is a Python-based project that reads employee sales data from a CSV file and calculates useful statistics such as total sales, average sales, highest sales, and lowest sales.
## Objective
To learn practical CSV file handling and data processing using Python.
## Technologies Used
- Python 3
- CSV Module
## Features
- Reads employee sales data.
- Calculates total sales.
- Calculates average sales.
- Identifies the highest sales value.
- Identifies the lowest sales value.
- Counts total and valid records.
- Handles missing and invalid values.
- Displays a summary report.
## Sample Dataset
Employee- Sales
Pujitha-15000
Ravi- 20000
Sita- 18000
Kiran- 12000
Arun-25000
Priya- 22000
## Expected Output
- Total Records: 6
- Valid Records: 6
- Total Sales: Rs. 112000.00
- Average Sales: Rs. 18666.67
- Highest Sales: Rs. 25000.00
- Lowest Sales: Rs. 12000.00

- Dictionaries
- Loops
- Functions
- Exception handling
- Mathematical operations

- Improved understanding of data analysis.
